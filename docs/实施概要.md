# 儿童汉字绘本阅读网站 · 实施概要

## 1. 项目目标

做一个**纯本地运行**的汉字绘本阅读网站，面向小学二年级左右的小朋友：

- 整个网站是一个文件夹，拷贝到任何电脑上，用浏览器打开即可使用，**无需安装、无需联网、无需服务器**。
- 绘本形式：每页一张配图 + 少量文字（全文 300~500 字，7~8 页，每页 20~50 字）。
- 点读拼音：小朋友遇到不认识的字，点一下该字，字的**上方浮现拼音**，停留一段时间后自动消失；停留时长**可配置**。
- 内容可持续扩充：故事文字、拼音、配图以约定好的文件格式存放，后续可以用 AI 或程序批量生成新故事，放进文件夹即可被网站识别。

## 2. 技术选型与关键约束

### 2.1 技术栈

| 部分 | 选择 | 理由 |
|---|---|---|
| 页面 | 原生 HTML + CSS + JavaScript（单页应用） | 零依赖、零构建，拷贝即用，长期不会因框架升级而失效 |
| 数据 | 每本书一个 `.js` 数据文件（内含 JSON 结构） | 见下面的 file:// 约束说明 |
| 拼音 | **内容生成时预先内嵌逐字拼音**（运行时不做转换） | 避免多音字出错（如"长大/长度"、"行走/银行"），AI 生成内容时按上下文给出正确读音 |
| 图片 | 本地图片文件（jpg/png/webp），与故事放在同一目录 | 离线可用 |

### 2.2 关键约束：file:// 协议下不能用 fetch 读 JSON

浏览器直接打开本地 `index.html` 时（`file://` 协议），出于安全限制，`fetch()`/`XMLHttpRequest` **无法读取本地 JSON 文件**。因此：

- 所有数据文件采用 `.js` 格式，通过 `<script>` 标签加载，文件内容形如 `window.registerBook({...})`；
- 新增故事时，需要在书架清单 `books/index.js` 里追加一行 `<script>` 注册（或由生成工具自动完成）；
- 这是"双击即可打开"方案的必然选择，需在文档和生成工具中明确约定。

## 4. 数据格式（内容导入的核心约定）

每本书的 `book.js`：

```js
window.registerBook({
  "id": "xiao-mao-diao-yu",
  "title": "小猫钓鱼",
  "cover": "images/cover.webp",
  "grade": 2,                       // 适读年级，可用于书架筛选
  "pages": [
    {
      "image": "images/p1.webp",
      "text": "小猫和妈妈一起去河边钓鱼。",
      "pinyin": ["xiǎo", "māo", "hé", "mā", "ma", "yì", "qǐ", "qù", "hé", "biān", "diào", "yú", ""]
    },
    {
      "image": "images/p2.webp",
      "text": "一只蜻蜓飞来了，小猫放下鱼竿去捉蜻蜓。",
      "pinyin": ["yì", "zhī", "qīng", "tíng", "fēi", "lái", "le", "", "xiǎo", "māo", "fàng", "xià", "yú", "gān", "qù", "zhuō", "qīng", "tíng", ""]
    }
  ]
});
```

约定要点：

- 中文：`pinyin` 数组与 `text` **逐字符一一对应**（标点对应空字符串），彻底规避运行时多音字判断；
- 英文：`lang` 为 `"en"`，每页用 `words` 数组（`{en, zh}`，标点只有 `en`），点词出中文并朗读；
- 校验规则简单明确：中文 `pinyin.length === Array.from(text).length`；英文每页必须有 `words`；
- 图片路径相对于本书文件夹；缺图时显示占位插画，不影响阅读文字。

`books/index.js`（按分类的书架清单）：

```js
window.loadBooks([
  {
    id: "ai",
    name: "AI 故事",
    hint: "新编的小童话",
    books: ["books/xiao-huo-long/book.js"]
  }
  // 新故事加到对应分类的 books 数组即可上架
]);
```

书架只渲染当前分类的封面图；阅读页翻到哪一页才加载那一页插图。仍兼容旧的扁平路径数组写法。

## 5. 核心交互设计

### 5.1 阅读页

- 上图下文（或左图右文，横屏自适应）；文字使用大号楷体/圆体，行距宽松；
- 每个汉字渲染为一个可点击的 `<span>`，标点不可点击；英文绘本按单词点击；
- 翻页方式：左右两侧大按钮 + 键盘方向键 + 触屏左右滑动；显示"第 x / n 页"。

### 5.2 点字出拼音 / 点词出中文

- 中文：点击某个字，上方弹出拼音气泡，并给该字加高亮底色；
- 英文（`lang: "en"`）：点击某个单词，上方弹出中文释义，并用 Web Speech API 朗读该词（`en-US`）；
- 气泡在**停留时长**结束后淡出消失；再次点击同一个字/词可立即关闭；
- 允许同时点亮多个字（比如整句都不认识时逐字点）。

### 5.3 设置（可配置项）

设置面板（齿轮图标打开），配置写入 `localStorage`：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 拼音停留时长 | 5 秒 | 可选 3 / 5 / 10 / 30 秒 / 不自动消失 |
| 字号 | 大 | 大 / 特大 |
| 整页拼音开关 | 关 | 开启后全文显示 ruby 拼音（辅助模式） |

## 6. 内容生产流程（AI / 程序生成）

1. `tools/prompt-template.md` 中提供标准提示词，核心要求 AI 输出：
   - 符合二年级识字量、情节有起伏的故事（全文 300~500 字，7~8 页，每页 20~50 字）；
   - **严格符合第 4 节的 book.js 格式**，拼音逐字标注、多音字按上下文选音、标点留空串；
2. 配图两种来源：AI 文生图（按每页文字生成提示词），或手工挑选的本地图片；统一压缩为 webp、长边 ≤ 800px（`tools/compress_images.py`），控制文件夹体积；
3. 导入 = 三步：新建 `books/<故事id>/` 文件夹 → 放入 `book.js` 和 `images/` → 在 `books/index.js` 对应分类追加路径；
4. 后续可选：写一个小的 Python/Node 校验脚本（本地开发用，非运行依赖），检查拼音对齐、图片存在性。

## 7. 实施步骤

**第一阶段：可用的最小版本**
1. 搭建 `index.html` 单页骨架：书架页（封面网格）+ 阅读页；
2. 实现数据加载（`books/index.js` → 各 `book.js` 注册）与翻页；
3. 实现点字出拼音气泡、定时消失、设置面板与 localStorage；
4. 制作 1 本示例书（含配图与逐字拼音），端到端跑通 `file://` 双击打开。

**第二阶段：内容生产配套**
5. 编写 AI 提示词模板与导入说明（README）；
6. 用模板生成 2~3 本新故事验证导入流程；
7. 补充整页拼音模式、字号设置、触屏滑动翻页。

**第三阶段（可选增强）**
8. 朗读功能：`speechSynthesis`（Web Speech API，离线可用，中文音色依赖操作系统）点字发音 / 整页朗读；
9. 生字本：点过的字记入 localStorage，提供"我的生字"复习页；
10. 阅读进度记忆：下次打开自动回到上次读到的页。

## 8. 验收标准

- 把整个文件夹拷到一台无网络的电脑，双击 `index.html`，Chrome/Edge/Safari 均能正常看书、点字出拼音；
- 拼音气泡按设置的时长自动消失，设置在关闭浏览器后仍保留；
- 按第 6 节流程新加一本故事，不改动任何代码即可出现在书架上；
- 多音字（如"长、行、着、了"）在示例故事中读音正确。
